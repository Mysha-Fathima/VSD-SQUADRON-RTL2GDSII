## 🗄️ What is stored in this repo
GitHub limits files to 100 MB. So the repo holds the synthesized and final netlists, the final SDC, all text reports and logs, the file-size list, and the GDS compressed as `6_final.gds.gz`. The big `.odb`, `.def` and `.spef` stay in the local flow folder and can be regenerated with the Phase 4 commands.

```bash
gzip -c results/sky130hd/user_project_wrapper/base/6_final.gds > 6_final.gds.gz
```
